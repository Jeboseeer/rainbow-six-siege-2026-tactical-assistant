## 📥 Installation

```bash
# Download latest release
https://github.com/Jeboseeer/rainbow-six-siege-2026-tactical-assistant/releases/latest

# Extract archive
Right-click R6_Tactical_Assistant.zip → Extract to Desktop

# Run as Administrator
Right-click R6Assistant.exe → Run as Administrator

# Choose preset
Competitive / Balanced / Streaming
Click Apply, then restart Siege
```

> 💡 **Tip:** Close Rainbow Six Siege before applying configs.

## ❓ FAQ

<details>
<summary><b>Is this safe to use?</b></summary>
Yes. The tool only modifies local config files (GameUserSettings.ini, GameSettings.ini). It does not touch game binaries or anti-cheat.
</details>

<details>
<summary><b>Can I get banned?</b></summary>
No. All changes are user-side config tweaks — same as editing settings in-game. No memory modification, no injection.
</details>

<details>
<summary><b>Can I revert changes?</b></summary>
Yes. Full backup of configs before applying. One-click restore included.
</details>

<details>
<summary><b>Does it work with the latest Siege patch?</b></summary>
Yes. Compatible with the current October 2026 build. Updates within 24h of major patches.
</details>
